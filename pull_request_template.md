## Type of change

- [ ] `fix`: bug fix
- [ ] `feat`: new behaviour
- [ ] `refactor`, `docs`, `ci`, `chore`: no behaviour change

## Checklist

- [ ] The PR title and every commit follow [Conventional Commits](https://www.conventionalcommits.org/): `type(scope): subject`.
- [ ] Type check and lint pass locally.
- [ ] Tests were run only with the maintainer's go-ahead; new logic and components have tests.
- [ ] User-facing text is translated (Spanish and English) and there are no hard-coded brand names.
- [ ] Accessibility is kept (WCAG 2.2 AA): keyboard, names, contrast, reduced motion.
- [ ] Docs, `README.md` and `.env.example` are updated when a script, variable or deploy changes.
- [ ] No secrets, tokens or personal data in the diff.
